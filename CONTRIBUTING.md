# Contribuir

El código propio usa MIT, Copyright (c) 2026 Guillem Carrion; terceros conservan sus licencias. El candidato aún espera destino y autorización de publicación. No se adopta un CLA ni se aceptan acuerdos nuevos. Al proponer cambios, describir problema y resultado con datos ficticios, añadir una regresión significativa cuando corresponda y ejecutar las pruebas de TESTING.md.

No enviar calendarios personales, capturas familiares, copias JSON privadas, credenciales o logs sin revisar. Para errores OCR usar un ejemplo sintético y documentar persona/mes/leyenda esperados, formato, navegador y salida parcial. No prometer interpretación universal, sincronización o precisión sin medición.

Conservar los avisos de terceros y documentar cualquier cambio de biblioteca. No incluir node_modules, dist, archivos de entorno, configuraciones locales de asistentes o historiales en los commits.
